Deploy

Upload ke InfinityFree

Upload semua file ke folder htdocs. Karena ini statis HTML/CSS/JS, tidak perlu Node.js atau proses build.

  1. Buka File Manager / FTP InfinityFree.
  2. Masuk ke folder htdocs.
  3. Upload index.html, folder assets, folder data, dan .htaccess.
  4. Akses domain/subdomain kamu dan tes tombol putar.
